# raspberry-pi-private-cloud

Final year project: self-hosted private cloud storage system using Raspberry Pi 4, Nextcloud, Linux, SSH, HTTPS and firewall configuration.
# Raspberry Pi Private Cloud Storage System

## Project Overview
This project focuses on designing, deploying and evaluating a low-cost private cloud storage system using Raspberry Pi 4 and Nextcloud.

## Aim
To build a self-hosted private cloud platform that provides secure file storage, user access control and remote access while evaluating performance, security and usability.

## Technologies Used
- Raspberry Pi 4
- Raspberry Pi OS
- Nextcloud
- Linux
- SSH
- UFW Firewall
- HTTPS / SSL
- WebDAV
- Netdata
- Fail2ban

## Key Features
- Private cloud storage deployment
- Secure file sharing
- User authentication
- Firewall configuration
- Remote access testing
- System monitoring
- Performance testing
- Troubleshooting and log analysis

## Implementation Summary
The system was installed and configured on a Raspberry Pi 4 using Raspberry Pi OS. Nextcloud was deployed to provide private cloud storage functionality. SSH access, firewall rules, HTTPS, trusted domains and system monitoring tools were configured to improve usability, security and reliability.

## Testing and Evaluation
Testing included file upload/download performance, service status checks, firewall verification, WebDAV access, system resource monitoring and troubleshooting of network-related issues.

## Challenges
- Changing local IP addresses
- Trusted domain configuration issues
- Self-signed HTTPS certificate warnings
- Hotspot/network instability
- Home network upload speed limitations

## What I Learned
This project helped me develop practical experience in Linux administration, cloud infrastructure, networking, security configuration, troubleshooting and performance evaluation.
